# Lot Review Dashboard

📊 **AsBuilt ISO Review Command Center**

Live dashboard tracking lot review comments across multiple lots with automated 3-hourly updates.

## Features

- 📊 Real-time statistics
- 👥 Assignee tracking
- 🔄 Auto-refresh every 3 hours
